# Crypto News Telegram Bot

Telegram-бот для ежедневного дайджеста мировых новостей и анализа их потенциального влияния на крипторынок.

## План MVP

- сбор новостей за последние 24 часа;
- отбор наиболее важных событий;
- AI-анализ влияния на BTC, ETH и крипторынок;
- ежедневная публикация в Telegram;
- ручная команда для получения текущего дайджеста;
- Docker-развёртывание.

## Локальный запуск

1. Создать виртуальное окружение.
2. Установить зависимости из requirements.txt.
3. Скопировать .env.example в .env.
4. Заполнить TELEGRAM_BOT_TOKEN и OPENAI_API_KEY.
5. Запустить python -m app.bot.

На текущем этапе бот содержит базовый каркас. Интеграции будут добавляться поэтапно.
