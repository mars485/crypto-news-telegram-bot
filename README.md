# Crypto News Telegram Bot

Telegram-бот для ежедневного дайджеста мировых новостей и анализа их потенциального влияния на крипторынок.

## Текущий MVP

- RSS-сбор новостей;
- фильтрация публикаций строго за последние 24 часа;
- удаление дублей;
- AI-анализ;
- выделение 5 наиболее значимых событий;
- влияние на BTC, ETH и крипторынок;
- ручная команда /today;
- автоматическая отправка каждый день в 08:00;
- Docker-развёртывание.

## Переменные окружения

Создай .env на основе .env.example:

- TELEGRAM_BOT_TOKEN — токен Telegram-бота;
- OPENAI_API_KEY — ключ OpenAI API;
- TELEGRAM_CHAT_ID — ID чата для ежедневной отправки;
- TIMEZONE — часовой пояс, по умолчанию Europe/Amsterdam.

## Как узнать TELEGRAM_CHAT_ID

1. Запусти бота.
2. Открой нужный чат с ботом.
3. Отправь /chatid.
4. Скопируй ID в .env.
5. Перезапусти контейнер.

## Docker на сервере

Клонируй репозиторий и перейди в каталог проекта:

    git clone https://github.com/mars485/crypto-news-telegram-bot.git
    cd crypto-news-telegram-bot

Создай .env:

    cp .env.example .env

Заполни TELEGRAM_BOT_TOKEN, OPENAI_API_KEY и TELEGRAM_CHAT_ID.

Запусти:

    docker compose up -d --build

Проверь состояние:

    docker compose ps

Посмотри логи:

    docker compose logs -f bot

## Расписание

По умолчанию дайджест отправляется каждый день в 08:00 по TIMEZONE.

## Проверка

1. /start — проверка Telegram.
2. /chatid — получение ID чата.
3. /today — ручной запуск полного дайджеста.
4. После настройки TELEGRAM_CHAT_ID ежедневная отправка выполняется автоматически.

## Следующий этап

После развёртывания добавим более устойчивый набор источников, контроль качества новостей и, при необходимости, отдельные уведомления о важных событиях вне ежедневного дайджеста.

## Устойчивость и диагностика

- RSS-источники загружаются параллельно; время ожидания HTTP-ответа каждого источника ограничено 15 секундами.
- При недоступности одного RSS-источника остальные продолжают обрабатываться. Если недоступны все источники, дайджест завершается ошибкой.
- Команда /today выполняет сетевые и AI-операции в отдельных потоках, не блокируя цикл обработки команд Telegram.
- В логах отдельно отображается продолжительность RSS и AI-этапов.
- Пользователь Telegram получает безопасное сообщение об ошибке без внутренних подробностей; диагностика доступна в логах сервера.

После обновления на VPS:

    git pull
    docker compose up -d --build
    docker compose logs --tail=100 -f bot

Проверка: отправь /today и убедись, что бот отвечает, а в логах появились строки Digest RSS stage и Digest AI stage. Эти изменения не затрагивают настройки .env и не изменяют ежедневное расписание.

## Кнопки Telegram

После /start или /menu бот показывает две inline-кнопки:

- 📰 Получить дайджест — запускает тот же процесс, что /today.
- ℹ️ Помощь — показывает команды и назначение кнопок.

После завершения дайджеста появляется меню для следующего действия. Повторные запросы дайджеста в одном чате, пока предыдущий ещё выполняется, отклоняются во избежание лишних расходов на OpenAI API. Ежедневная автоматическая отправка не меняется.

Обновление на VPS: `git pull origin main && docker compose up -d --build`. После запуска отправь боту /start и проверь все три кнопки.

Кнопка ID чата удалена из меню; техническая команда /chatid остаётся доступной для администратора при настройке.

## Оформление дайджестов

AI формирует компактный пост в стиле новостного издания: заголовок, краткое резюме, до пяти событий с нумерацией и ссылками, отдельный блок по BTC/ETH, «Что отслеживать» и дисклеймер. Telegram HTML используется и для /today, и для ежедневной рассылки; предпросмотр ссылок отключён. Если пост слишком длинный, отправка переключается на обычный текст, чтобы не разорвать HTML-разметку.

Для проверки после обновления VPS: `git pull origin main && docker compose up -d --build`, затем отправь `/today`. Важно: оформление AI-ответа зависит от соблюдения моделью HTML-инструкций; при некорректном HTML Telegram может отклонить отправку, что будет отражено в логах.
