# Crypto News Telegram Bot

Telegram-бот для ежедневного дайджеста мировых новостей и анализа их потенциального влияния на крипторынок.

## Что умеет MVP

- сбор новостей из RSS;
- AI-анализ новостей;
- выделение наиболее значимых событий;
- оценка потенциального влияния на BTC, ETH и крипторынок;
- ручная команда /today;
- автоматическая отправка каждый день в 08:00;
- Docker-развёртывание.

## Переменные окружения

Создай .env на основе .env.example:

- TELEGRAM_BOT_TOKEN — токен Telegram-бота;
- OPENAI_API_KEY — ключ OpenAI API;
- TELEGRAM_CHAT_ID — ID чата, куда отправлять ежедневный дайджест;
- TIMEZONE — часовой пояс, по умолчанию Europe/Amsterdam.

## Как узнать TELEGRAM_CHAT_ID

1. Запусти бота.
2. Открой нужный чат с ботом.
3. Отправь команду /chatid.
4. Скопируй полученный ID в .env.
5. Перезапусти контейнер/бота.

## Расписание

По умолчанию ежедневный дайджест отправляется в 08:00 по TIMEZONE.

Чтобы изменить время, отредактируй app/scheduler.py.

## Локальный запуск

1. Создать виртуальное окружение.
2. Установить зависимости из requirements.txt.
3. Скопировать .env.example в .env.
4. Заполнить переменные окружения.
5. Запустить:

python -m app.bot

## Docker

Собрать и запустить:

docker compose up -d --build

Проверить логи:

docker compose logs -f bot

На следующем этапе можно добавить фильтрацию строго за последние 24 часа, более устойчивые источники новостей и Docker-развёртывание на домашнем сервере.
